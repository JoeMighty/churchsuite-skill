# Permission matrix starter

Levels: None, Use, Write, Manage. Give the least needed. Set site access separately.

| Role | Address Book | Children | Calendar | Small Groups | Rotas | Giving | Bookings | Account |
|---|---|---|---|---|---|---|---|---|
| Administrator | Manage | Manage | Manage | Manage | Manage | Manage | Manage | Admin |
| Office staff | Write | Write | Write | Write | Write | None | Write | User |
| Children's lead | Use | Write | Use | None | Use | None | None | User |
| Treasurer | Use | None | None | None | None | Manage | None | User |
| Pastor | Write | Use | Use | Use | Use | None | None | User |
| Volunteer (events) | Use | None | Write | None | None | None | Use | User |
| Web volunteer | None | None | None | None | None | None | None | API user only |

Notes:
- Group leaders and ministry overseers use My ChurchSuite and need no module permission.
- Giving access should be as few people as possible.
- Review every 6 months and after anyone leaves. Archive users who leave.
- This is a starting point, not a rule. Adjust to your church.
