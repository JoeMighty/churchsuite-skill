# Contributing

Thanks for helping keep this skill accurate.

## Good contributions

- Corrections to a menu name, setting, limit or behaviour, with a link to the support article or developer page that shows it.
- New recipes for ministry scenarios.
- Updates when ChurchSuite releases or retires features (see the "Ongoing updates" blog posts).
- Evals in `evals/` for questions the skill answers badly.

## Rules

- Never include real personal data, client secrets, tokens or account URLs of real churches.
- Do not paste large passages from the support site. Summarise in your own words and link to the source.
- Mark anything uncertain with "verify" and a source rather than guessing.
- Keep `SKILL.md` short. Detail belongs in `references/`.
- Keep reference files under about 400 lines and update `references/18-source-index.md` when adding sources.
- Plain text style: no em or en dashes.

## Pull request checklist

- [ ] Source link included for each factual change
- [ ] No secrets or personal data
- [ ] `SKILL.md` frontmatter still valid (`name`, `description`)
