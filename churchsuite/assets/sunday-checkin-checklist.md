# Sunday Check-In checklist

Before (Saturday):
- [ ] Sessions and groups are correct for tomorrow
- [ ] Devices charged, Check-In app updated
- [ ] Printer paper and labels loaded

On arrival (30 min before):
- [ ] Check-In running on every device
- [ ] Print test on each device
- [ ] Volunteers briefed, safeguarding lead present
- [ ] Allergy and medical info visible to group leaders

During:
- [ ] Late arrivals checked in
- [ ] Unrecognised child or parent handled by the safeguarding lead

After:
- [ ] Everyone checked out
- [ ] Attendance reviewed
- [ ] Issues noted for next week
