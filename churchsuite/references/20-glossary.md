# Glossary

Plain meanings of ChurchSuite terms for newcomers.

| Term | Meaning |
|---|---|
| Account | Your church's whole ChurchSuite setup. |
| Administrator | A user with account wide control. Other users are limited by module permissions. |
| Module | A feature area such as Address Book, Rotas or Giving. |
| Permission levels | None, Use, Write, Manage, set per module per user. |
| Site | A church location. Multi-site accounts share settings but limit users and data by site. |
| Contact | An adult in the Address Book. |
| Child | A child or young person in the Children module, linked to parents or carers. |
| Status | Active (processed), Pending (new, unconfirmed), Archived (kept but ignored). |
| Tag | A label on people. Fixed tags are hand picked. Smart tags follow rules and update themselves. |
| Key date | A dated fact about a person, such as baptism or DBS expiry. |
| Flow | A step by step process for following someone up, with stages and tasks. |
| Custom field | An extra data field you define. |
| Form | An online form (newcomer, event sign up, consent) that feeds the database. |
| Person detection | Matching form entries to existing people to avoid duplicates. |
| Sequence | A repeating event or booking. Edits can apply to one date or the whole sequence. |
| Embed | Pasteable code that shows ChurchSuite content on your website. |
| JSON feed | Public data version of embed content, no personal data. |
| API | Programmatic access for developers. v2 is current, v1 is deprecated. |
| My ChurchSuite | The member facing website and app. |
| Connect | Older information point tool. Child check-in in Connect was retired on 31 May 2026. |
| Check-In | The standalone app for checking children in and printing badges. |
| Ministry | In Rotas, an area of serving. Contains teams and roles. |
| Overseer | A person who manages a ministry's rotas without needing module access. |
| Unavailability | Dates a person cannot serve, blocking all rotas. |
| Decline | Saying no to one rota date. |
| Giver | A person or organisation who gives, in the Giving module. |
| Fund | A pot donations are assigned to. |
| Declaration | A donor's signed Gift Aid statement (UK). |
| Claim | A batch of Gift Aid donations sent to HMRC. |
| Gift Aid | UK tax relief on eligible donations. |
| Donate | Online giving form. |
| Merge field | A placeholder like a first name, filled in per recipient. |
| Preset | A saved email or SMS template. |
| Data protection contact | The named person who receives privacy notifications. |
| GDPR | UK and EU data protection law. |
| Right to be forgotten | A person's request to have data erased. ChurchSuite flags it, you act. |
| CharitySuite | The sister product for charities, with its own login domain. |
