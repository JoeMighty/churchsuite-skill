# 30 day onboarding plan

For a church new to ChurchSuite. Adjust to the modules you actually bought. Small steps, check each before moving on.

## Week 1: Foundations
- Name an Administrator and a data protection contact.
- Add sites if you have more than one.
- Add users with least needed permissions (assets/permission-matrix.md).
- Set the church name, logo, sender email and brand in Account Settings.
- Decide naming conventions for tags and fields (assets/naming-conventions.md).
- Upload your data protection statement.

## Week 2: People
- Clean your spreadsheet. Run scripts/csv_preimport_check.py.
- Import a small test batch, then the rest (assets/import-contacts.csv).
- Import children and link them to parents by hand.
- Create 5 to 10 core tags, one newcomer flow, and the key dates you really use.
- Build your first smart tag (for example: active members in a site).

## Week 3: Run the church
- Calendar: add the regular events as sequences.
- Small Groups or Rotas: set up the one you will use first.
- Children: sessions, groups and Check-In devices. Do a dry run with volunteers (assets/sunday-checkin-checklist.md).
- Turn on My ChurchSuite and send invitations to a pilot group.

## Week 4: Reach out and secure
- Send a first email using a preset and merge fields.
- Giving (if used): import givers, set funds, test one donation and, in the UK, one Gift Aid declaration.
- Website: add a Calendar embed or Small Groups embed.
- Review permissions and run the account health audit (assets/account-health-audit.md).
- Schedule a monthly 30 minute data tidy.

## Done means
Everyone who needs to log in can, one real Sunday has run through the system, and someone owns data quality.
