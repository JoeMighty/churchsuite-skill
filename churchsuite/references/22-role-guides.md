# Role guides

What each person usually needs. Use these to tailor answers to who is asking.

## Office administrator
Owns data quality and users. Daily: new contacts, status changes, emails. Monthly: merge duplicates, review Pending contacts, run the health audit. Key refs: 01, 11, 12, 13, 17, 19.

## Ministry overseer
Manages one ministry's rotas in My ChurchSuite without module access. Handles swaps, declines, unavailability notices. Key refs: 05, 10.

## Small group leader
Sees their group, takes attendance, emails members, usually via My ChurchSuite. Needs simple steps and no admin jargon. Key refs: 04, 10.

## Children's lead
Runs sessions, groups, Check-In devices, badges, allergies and consents. Needs a Sunday checklist and a fix list for check-in problems. Key refs: 02, 17, assets/sunday-checkin-checklist.md.

## Treasurer or giving administrator
Records donations, funds, Gift Aid declarations and claims. Needs accuracy and an audit trail. Key refs: 06, 17, scripts/giving_csv_check.py.

## Web or tech volunteer
Embeds, JSON feeds, API. Keep secrets out of browser code, request read only scopes, use a dedicated API user. Key refs: 15, scripts/.

## Member
Uses My ChurchSuite to update details, see groups and rotas, give. Answer in friendly plain language and avoid admin menus they cannot see. Key refs: 10.

## Senior leader or trustee
Wants reports and assurance, not clicks. Summarise: attendance trends, giving health, data protection status, user permissions. Key refs: 08, 14, assets/account-health-audit.md.
